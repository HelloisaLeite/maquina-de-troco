# Máquina de Troco

Projeto desenvolvido em **JavaScript e React** para calcular o troco de uma compra e informar a quantidade de notas e moedas que devem ser devolvidas.

## Funcionalidades

* Receber o valor da compra.
* Receber o valor pago.
* Calcular o troco.
* Informar a quantidade de cada nota e moeda utilizada no troco.

## Tecnologias

* React
* JavaScript
* HTML
* CSS

## Projeto

Projeto desenvolvido como atividade acadêmica para colocar em prática conceitos de **componentes, props, useState e eventos**.
